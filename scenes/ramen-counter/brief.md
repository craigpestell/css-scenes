# Ramen Counter (ramen-counter)

Status: APPROVED by the user on 2026-10-03, after the build and review. Built on 2026-10-02 from the shortlist in `ideas/gallery-inspiration.md`, using the defaults below, which Claude picked.

## Concept / mood / motion language
- **Concept:** Sitting at a late-night ramen counter. A bowl steams in front of an open doorway, a red paper lantern sways, a navy noren reading らーめん stirs in gusts, and menu tags hang on the wall.
- **Mood:** Warm, quiet and cosy. It is the stop after the Tokyo Subway ride.
- **Motion language:** Slow, organic, a little irregular.

## Defaults picked
1. Companion to Tokyo Subway: same `--c-*` token set available (in the end none are used), `light-dark()` palette, system fonts only, no JS.
2. The doorway is a dark street in both schemes, so the white steam always has contrast.
3. Light scheme = a bright, pale-wood shop interior; dark = dim, dark-wood interior.
4. Scene colours are local custom properties; nothing is added to `tokens.json`. Accepted exception to the token rule (user, 2026-10-03).
5. Reduced motion: noren, lantern and steam freeze; the steam stays visible as a still wisp.

## Inspiration
[Rise & Steam (sleepy dumplings)](https://codepen.io/GemmaCroad/pen/bNqWNWx) by Gemma Croad; this gallery's Tokyo Subway.
