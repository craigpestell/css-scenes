# css-scenes

CSS-only scene gallery. The `project-architecture` skill in `.claude/skills/` maps the repo; `/new-scene` runs the scene pipeline.

## Team

The project is run by the Lite agent team from [company-kit](https://github.com/craigpestell/company-kit) plus the scene agents in `.claude/agents/`. Read `docs/team/README.md` (handbook) and `docs/team/project.md` (stack, commands, rules, deploy gate, what needs the founder) before starting work.
